# AI CEO

AI CEO is a local AI study assistant for mathematics and geometry.

## Features

- AI mathematics tutoring
- Geometry problem solving
- Step-by-step explanations
- Image-based question support
- Chat history
- New Chat
- Rename Chat
- Delete Chat
- Upload image
- Remove image
- Local Ollama AI

## Requirements

- macOS
- Python 3
- Ollama
- An Ollama-compatible AI model

## Installation

Create a Python environment:

python3 -m venv .venv

Activate it:

source .venv/bin/activate

Install requirements:

pip install -r requirements.txt

Install Ollama separately and download a compatible model.

## Run

python study_assistant.py
